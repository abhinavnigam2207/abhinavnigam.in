# Design brief — Abhinav Nigam

## Direction
Minimal editorial portfolio: let Abhinav's engineering experience and measurable outcomes carry the visual weight. Reference the clear destinations in Aahana Bobade's landing page, curated project structure at akkila.dev, requested section anatomy at Abhinav's existing portfolio, and compact dated writing/timeline patterns from Lee Robinson and Brittany Chiang. Do not copy the IDE chrome, animation, gradients, or any high-density decoration.

## Design dimensions
- **Movement:** contemporary editorial / quiet Swiss-inspired web typography.
- **Core principles:** clear hierarchy, generous breathing room, direct navigation, factual copy, accessible contrast, responsive layouts.
- **Color philosophy:** warm paper background, near-black ink, medium neutral gray, thin pale dividers, one restrained cobalt accent. Dark surfaces only for small utility details, not an elaborate dark-mode treatment.
- **Layout paradigm:** centered, reading-width column for text; a wide but sparse hero; thin grid/column rhythm for roles, project facts, and lists; repeatable cards only where they improve scanning.
- **Signature elements:** small “AN” monogram, crisp section numbers, simple arrow/link affordances, concise metadata labels; no stock imagery or pretend product mockups.
- **Interaction:** native links, obvious focus states, readable form labels, keyboard-accessible controls, no surprising scroll hijacking.
- **Animation:** none required; use only a subtle short hover/focus transition and respect reduced-motion preferences.
- **Typography:** robust system sans for UI, system serif or a restrained display face for large headings if locally available; keep body text comfortable and avoid a new font download dependency.
- **Brand essence and voice:** experienced, thoughtful, approachable software engineer; precise and evidence-led, not salesy.
- **Wordmark/logo:** “AN” geometric monogram in a filled near-black N silhouette against warm paper; use the same mark as the favicon and site identity.
- **Signature color:** subdued cobalt, reserved for links, indicators, and primary actions.

## Asset decision
This is a text-led engineer portfolio, so no decorative hero photo or stock illustrations are needed. Create one simple original geometric monogram asset and favicon; all remaining motifs should be CSS or semantic text.
